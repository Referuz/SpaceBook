# SpaceBook
[ Software encargado de administrar salas o espacios para diferentes personas.
Consiste en resolver el problema de un edificio con varias salas disponibles para los internos,
cada interno por ejemplo maestros, necesitan la sala a corde a las amenidades que necesitan, por lo que
se resuelve el choque de peticion de las salas, además de digitalizar los registros a papel.]
